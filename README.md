
# Cybersecurity & Penetration Testing Lab Setup

## Project Overview
This project is part of my Cybersecurity program at Networkwalks (Batch B084B).

The objective was to set up a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux and understand basic virtual machine networking.

## Tools Used
- Oracle VirtualBox
- Kali Linux
- Virtual Machine Networking

## Tasks Completed
- Installed and configured Oracle VirtualBox
- Imported and configured Kali Linux
- Created a private NAT Network
- Verified IP configuration
- Tested network connectivity
- Tested DNS resolution
- Created a VM snapshot for recovery (if completed)

## Key Learnings
- Virtual machine setup and configuration
- NAT vs. NAT Network
- IP addressing and network connectivity
- DNS resolution
- Virtual machine snapshots and recovery
